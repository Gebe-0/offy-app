# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.
Report vulnerabilities privately through [GitHub Private Vulnerability Reporting](https://github.com/Gebe-0/offy-app/security/advisories/new) or via email to `support@offy.app`.

Include:
- Affected component and version
- Clear description of the vulnerability and potential impact
- Steps to reproduce (defensive minimal reproduction)

We will acknowledge receipt within 72 hours and coordinate a fix before public disclosure.

## Supported Versions

Only the latest published release receives security updates.
